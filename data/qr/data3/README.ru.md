# Реальные складки

20 PNG-кропов с одним целым QR, полученных из 18 фотографий. Применён только целочисленный кроп без изменения разрешения, поворота и обработки пикселей. Исходные фотографии сохранены локально в `test/fold_data` и исключены из Git.

На фотографиях два напечатанных QR версии 5 (37×37): 12 кадров с EC L и 8 с EC Q. Ожидаемые строки проверены по совпадению деталей двух физических символов с эталонами и по декодированию геометрически восстановленных фотографий.

Единственный `manifest.json` содержит строки, координаты кропов и SHA-256 оригиналов и PNG. Эти данные необходимы для воспроизводимой проверки:

```powershell
python test/fold_test.py
```

Скрипт проверяет точное совпадение строк, seed 1 и хеши PNG; при наличии оригиналов проверяются и их хеши. Для запуска достаточно `data/qr/data3`, исходные JPEG не требуются. По умолчанию выводится один процент. Дополнительные параметры: `--baseline <exe>`, `--repeat <n>`, `--details <json>`.

Текущий C++-сканер: **14/20 (70%)**.
